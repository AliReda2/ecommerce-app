## 📘 Overview

The **E-Commerce App** mirrors real-world e-commerce platforms, integrating a full product catalog, cart and checkout flows, user accounts, and a complete admin dashboard.

This repository provides documentation only—no proprietary code.

---

## ⭐ Features Overview

### 👤 User Features

| Capability           | Description                                |
| -------------------- | ------------------------------------------ |
| 🛍️ Product Browsing | Categories, filtering, and product details |
| 🛒 Cart System       | Add, remove, and adjust quantities         |
| 💳 Checkout          | Order placement and confirmation           |
| 🔐 Authentication    | Register, log in, manage profile           |
| 📱 Responsive UI     | Optimized for mobile and desktop           |

### 🛠️ Admin Dashboard

| Capability            | Description                    |
| --------------------- | ------------------------------ |
| 📦 Product Management | Add, edit, and remove products |
| 🗂️ Categories        | Full CRUD management           |
| 🖼️ Hero Slides       | Manage promotional banners     |
| 📑 CMS Controls       | General platform settings      |
| 🚚 Orders             | Update order statuses          |
| 👥 Users              | Role and account management    |

### ⚙️ Technical Features

| Technical Capability    | Description                                  |
| ----------------------- | -------------------------------------------- |
| 🔗 REST API             | Clean and modular service endpoints          |
| 🔐 Token Auth           | Access + refresh tokens via HttpOnly cookies |
| 🧹 Validation           | Structured DTO validation and error handling |
| ⚡ State Management      | Redux Toolkit integration                    |
| 🧩 Modular Architecture | Reusable services, components, and schemas   |
